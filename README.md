# PTDT-TriState-Unified-v33

Virtual Tri-State River Valley — cinematic CGI digital twin + Windows 11 standalone

**Full setup:** see [SETUP.md](./SETUP.md)

## Quick start (Windows 11)

```powershell
git clone https://github.com/ATphobia22/PTDT-TriState-Unified-v33.git
cd PTDT-TriState-Unified-v33
npm install
.\scripts\build-win11.ps1
```

→ `release\PTDT-Unified-V33-Portable.exe`

## Dev

```powershell
npm run dev
```

## Features

- MapLibre dark basemap + Three.js river valley
- ACESFilmic tone map, depth-driven grade/fog
- Cinematic camera tracks · flood water shader
- Forensic HUD · USGS 03378500 · Bishop FoS ≥ 1.40
- HEC-RAS bridge · PostGIS · Inno Setup optional
