# FEMA LOMR-F + Indiana regulated drain easements

## LOMR-F vs LOMA

| | **LOMA** | **LOMR-F** |
|---|---|---|
| Ground | **Natural** grade (no fill) | Elevated by **fill** |
| Form | MT-EZ (single) / MT-1 | **MT-1** / Online LOMC only |
| FEMA fee | **None** | **Yes** (44 CFR Part 72 schedule) |
| Structure test | LAG ≥ BFE | LAG ≥ BFE + community “reasonably safe from flooding” |
| Lot test | Lowest lot elev ≥ BFE | Same + fill documentation |
| Floodway | Outside / natural | Fill **outside existing regulatory floodway** (LOMR-F definition) |

**CLOMR-F** = conditional (proposed fill) before construction; final LOMR-F uses as-built elevations.

**PTDT path for Bonebank:** Material Truth claims **natural** +2.2 ft clearance → prefer **LOMA**, not LOMR-F. Use LOMR-F only if survey shows engineered fill raised the grade.

Online LOMC: https://hazards.fema.gov/onlinelomc/

## Indiana regulated drain right-of-entry (IC 36-9-27-33)

| Rule | Value |
|---|---|
| Default ROW | **75 ft** each side, measured at right angles from tile **centerline** or open-drain **top of bank** |
| Post-1984 / urban drains | Board may reduce to **≥25 ft** (open) / **≥15 ft** (tile) |
| Platted subdivision tile | Further reduction possible, not below **7 ft** each side of centerline |
| Structures in ROW | Require **Drainage Board written consent** |
| Authority | County Surveyor + Drainage Board (IC 36-9-27) |

Handbook: Indiana Drainage Handbook (IDNR-hosted PDF, not IDNR policy itself).

**Operator:** Before berm/fill/structures near county drains, clear Posey County Surveyor / Drainage Board — separate from DNR floodway (IC 14-28-1).
