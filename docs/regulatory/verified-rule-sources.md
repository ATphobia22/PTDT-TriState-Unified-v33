# Verified floodway rule sources

Verification date: 2026-08-10

This document records source text and scope for machine evaluation. It does not provide legal advice or certify a project.

## Illinois

**17 Ill. Adm. Code Part 3700 — Construction in Floodways of Rivers, Lakes and Streams**

Official source: https://www.ilga.gov/agencies/JCAR/EntirePart?titlepart=01703700

Section 3700.20 defines a floodway as the channel and portion of floodplain needed to convey the 1% annual-chance flood discharge with no more than a 0.1-foot increase in stage due to loss of conveyance/storage. That 0.1-foot value is a floodway delineation definition; it must not be converted into a universal project no-rise certification rule.

Scope exclusions in the rule include counties where floodway limits are defined under 17 Ill. Adm. Code 3708.

## Kentucky

**401 KAR 4:060 — Floodplain Management — Uses of Regulatory Floodway**

Official source: https://apps.legislature.ky.gov/law/kar/titles/401/004/060/

Section 4(1) states that, subject to exceptions, encroachments in the regulatory floodway require certification with supporting technical data by a licensed engineer demonstrating no impact / no increase in flood levels during the base flood discharge.

The system must not encode a generic "1.0 ft freeboard" rule as though it were the universal 401 KAR 4:060 floodway standard.

## Indiana

**312 IAC 10-2-3 / Indiana DNR floodway guidance**

Official source: https://www.in.gov/dnr/water/regulatory-permit-programs/exemptions/

Indiana DNR defines an adverse effect on floodway efficiency/capacity using a 0.15-foot increase in regulatory flood elevation, subject to stated exceptions.

**FEMA-mapped floodways:** Indiana DNR's current no-rise guidance explains that FEMA-mapped floodway projects must demonstrate no increase in flood heights or follow the applicable FEMA CLOMR/LOMR process. Indiana DNR separately notes its state regulation can allow up to a 0.14-foot cumulative surcharge, but that does not replace the FEMA no-rise requirement for FEMA-mapped floodways.

Official source: https://www.in.gov/dnr/water/surface-water/indiana-floodplain-mapping/no-rise/
