# Posey County GIS, APC, and historical plats

## Live GIS / assessor

| System | URL | Use |
|--------|-----|-----|
| XSoft Engage | https://engage.xsoftinc.com/posey | Parcel detail, assessments (proxy via FastAPI; no browser CORS) |
| WTH GIS | http://posey.in.wthgis.com/ | Interactive parcels / overlays |
| IGIO parcels (state) | Parcel_Boundaries_of_Indiana_Current FeatureServer | Statewide harvest boundaries |

Parcel IDs follow **50 IAC 26-8-1** digit patterns (e.g. `65-##-##-###-###.###-###`).  
Sample WTH query strings are **not** automatic Bonebank APN proof — reconcile with deed.

## Area Plan Commission

- https://www.poseycountyin.gov/county-offices/area-plan-commission/  
- Improvement Location Permit, zoning, UDO  
- Floodplain construction still needs **IDNR / local floodplain admin** + FARA as applicable  

## Historical plats (heritage only)

Indiana State Library Posey County maps:  
https://www.in.gov/library/collections-and-services/indiana/indiana-county-maps-atlases-and-plat-books/posey-county-maps/

Includes 1870 ownership map, 1873 Mt. Vernon vicinity, 1900/1909 atlases, later plat books.  
**Not** regulatory for BFE, BAFL, or LOMA.

## Archaeology (overlay only)

Murphy Site, Ashworth Site, Hovey Lake Archaeological District (Caborn-Welborn) — NRHP context; no hydraulic authority.
